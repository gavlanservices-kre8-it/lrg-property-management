# LRG Property Management Website

A responsive static website for LRG Property Management.

## Launch checklist
1. Open `index.html` locally to preview.
2. The contact form is configured to send inquiries to `lrg6657@gmail.com`.
3. Replace the placeholder project cards with actual project names/descriptions and photos.
4. Deploy the folder to Vercel, Netlify, GitHub Pages, Shopify custom page environment, or any static web host.

## Project photos
The demo project cards use gradients so the site works without image files. Add project images in the folder and replace the `background-image` values for `.project-one`, `.project-two`, and `.project-three` in `styles.css`.

## Logo
The LRG logo is an inline SVG monogram embedded directly into the header/footer, so it stays sharp at every screen size and requires no external logo file.
